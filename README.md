
# NutriPilot React Demo

Interaktiver UX-Prototyp für einen digitalen Arbeitsplatz in der klinischen Ernährung.

## Direkt auf GitHub Pages

1. Den Inhalt dieses Ordners in ein GitHub-Repository hochladen.
2. Darauf achten, dass `index.html` im Stammverzeichnis liegt.
3. Unter **Settings → Pages** die Veröffentlichung aus `main` und `/(root)` aktivieren.
4. Die von GitHub angezeigte `github.io`-Adresse öffnen.

## Technische Hinweise

- Die Demo verwendet React 18 und Babel über öffentliche CDN-Skripte.
- Es ist kein Build-Schritt erforderlich.
- Die Anwendung enthält ausschließlich erfundene Demodaten.
- Für echte Gesundheitsdaten ist dieses Hosting- und Sicherheitsmodell nicht geeignet.
- Die Demo ist für Desktop und iPad responsive gestaltet.
