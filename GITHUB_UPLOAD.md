# Upload in das bestehende GitHub-Repository

Repository: `nnft7rhyt8-byte/nutrition-assistant-demo`

1. ZIP entpacken.
2. GitHub öffnen und das Repository aufrufen.
3. `Add file` → `Upload files` wählen.
4. Aus dem entpackten Ordner diese sichtbaren Elemente gemeinsam in die Upload-Fläche ziehen:
   - `src`
   - `index.html`
   - `package.json`
   - `vite.config.js`
   - `README.md`
5. Vorhandene Dateien ersetzen lassen und unten `Commit changes` wählen.
6. Unter `Actions` den Workflow `Deploy NutriPilot to GitHub Pages` abwarten.
7. Danach öffnen: `https://nnft7rhyt8-byte.github.io/nutrition-assistant-demo/`

Die vorhandene versteckte `.github`-Struktur muss für dieses Update nicht erneut hochgeladen werden.
